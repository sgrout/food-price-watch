# Basket export sample

A small, real sample of the optional basket export (one basket per country). Contract:
`docs/export-contract.md` section 4b; schemas: `export/schema/basket_*.schema.json`. Regenerate with
`scripts/make_basket_sample.py`.

Source: World Food Programme (WFP), food prices via the Humanitarian Data
Exchange (HDX), licensed CC BY-IGO 3.0. Baskets and forecasts: Staple Signals (not an official MEB).

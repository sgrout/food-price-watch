# Test fixtures

Trimmed copies of real downloads, used by the tests:

- `wfp_food_prices_mli_head.csv`: the first 20 rows of WFP's food price file for Mali.
- `hdx_package_show_nga.json`: a trimmed CKAN `package_show` response for WFP's Nigeria dataset.
- `hdx_redirect_page.html`: the HTML redirect page the HDX download URL returns (the pre-signed S3 query string,
  which held temporary credentials, is replaced by `REDACTED`).

Source: World Food Programme (WFP), food prices via the Humanitarian Data Exchange (HDX), licensed CC BY-IGO 3.0
(https://creativecommons.org/licenses/by/3.0/igo/).

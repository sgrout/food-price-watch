# À propos de Staple Signals

Staple Signals (staplesignals.org) est un projet ouvert, gratuit et non commercial. Il alerte tôt sur la hausse des prix des denrées
de base sur les marchés locaux, avec des prévisions honnêtes sur leur incertitude et un historique publié de leur
fiabilité. Il s'adresse aux petites ONG, aux organisations locales, aux journalistes et aux chercheurs qui n'ont pas
leur propre équipe de données.

Il complète les évaluations officielles de la sécurité alimentaire du Programme alimentaire mondial et de FEWS NET,
sans les remplacer : [HungerMap du PAM](https://hungermap.wfp.org) · [FEWS NET](https://fews.net).

**Données.** Prix des denrées : Programme alimentaire mondial (PAM), publiés sur le Humanitarian Data Exchange
(HDX), sous licence CC BY-IGO. Les données sont mises à jour chaque semaine à partir des fichiers du PAM ; les prix
d'un mois paraissent un à plusieurs mois plus tard.

**Aucune donnée personnelle.** Pas de cookies, pas de comptes ni de données personnelles ; comptage anonyme des visites (Vercel Web Analytics).

**Statut.** Ceci est une version bêta : le suivi en conditions réelles vient tout juste de commencer. Les prévisions couvrent le Mali, le Burkina Faso, le Burundi et le Niger.

Le code est ouvert (licence MIT) : https://github.com/sgrout/food-price-watch.

# site-requests/

Questions and requests from the site side to the data side. One file per topic:
`YYYY-MM-DD-<short-topic>.md`. Template:

```markdown
# <short title>

Status: open            <!-- open | answered | accepted (version/commit) | declined (reason) -->
From: site agent, YYYY-MM-DD

## Request
What is needed and why (which page or feature, which user need).

## Example
The data or field as you would like to receive it (JSON snippet), or the problem you see (file, id, value).

## Answer
(written by the data side)
```
